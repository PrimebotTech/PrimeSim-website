# PrimeSim project page

Static project page for PrimeSim, built with [Astro](https://astro.build).

```sh
cd website
npm ci
npm run dev      # http://localhost:4321
npm run build    # static output in website/dist
```

Pushing to `main` builds and deploys the site to GitHub Pages
(`.github/workflows/astro.yml`). See `website/README.md` for the page structure.
